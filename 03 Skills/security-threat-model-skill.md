# Threat Model Skill

**来源**: `~/.codex/skills/security-threat-model/`  
**用途**: 基于仓库的威胁建模，枚举信任边界、资产、攻击路径和缓解措施

## 工作流程（8 步）

### 1. 范围界定与系统模型提取
- 识别主要组件、数据存储、外部集成
- 区分运行时行为 vs CI/构建/开发工具 vs 测试/示例

### 2. 推导边界、资产和入口点
- 信任边界：协议、认证、加密、验证、限速
- 资产：数据、凭证、模型、配置、计算资源、审计日志
- 入口点：端点、上传、解析器、任务触发器、管理工具、日志/错误输出

### 3. 校准资产和攻击者能力
- 列出关键资产（凭证、PII、完整性关键状态、可用性关键组件）
- 基于暴露面描述实际攻击者能力

### 4. 枚举威胁（滥用路径）
- 以攻击者目标为导向（泄露、提权、完整性破坏、拒绝服务）
- 分类并与资产关联

### 5. 优先级排序
- 可能性 × 影响（低/中/高）
- 综合优先级（低/中/高/严重）

### 6. 验证假设
- 向用户确认关键假设
- 提出 1-3 个针对性问题

### 7. 推荐缓解措施
- 区分现有措施（有证据）和推荐措施
- 关联到具体位置和措施类型

### 8. 质量检查
- 所有入口点是否覆盖？信任边界是否都有对应威胁？
- 运行时 vs CI/开发是否分离？

## 风险优先级参考

| 等级 | 示例 |
|------|------|
| 🔴 严重 | 预认证 RCE、认证绕过、跨租户访问、密钥窃取 |
| 🟡 中 | 关键组件定向 DoS、部分数据泄露、日志投毒 |
| 🟢 低 | 低敏感信息泄露、易缓解的 DoS、极低概率问题 |
