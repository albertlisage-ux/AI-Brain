# UI/UX Pro Max - Design Intelligence

**来源**: `~/.codex/skills/ui-ux-pro-max/`  
**用途**: 全面的 UI/UX 设计智能库（50+ 风格、161 配色、57 字体搭配、161 产品类型、99 UX 指南、25 图表类型）

## 适用场景

- 设计新页面（着陆页、仪表盘、管理后台、SaaS、移动应用）
- 创建或重构 UI 组件
- 选择配色、字体、间距、布局
- 审查 UI 代码的体验、可访问性、视觉一致性
- 实现导航、动画、响应式行为

## 规则优先级（1-10）

| 优先级 | 类别 | 影响 | 关键检查点 |
|--------|------|------|-----------|
| 1 | 可访问性 | 🔴 严重 | 对比度 4.5:1、Alt 文本、键盘导航、ARIA 标签 |
| 2 | 触摸与交互 | 🔴 严重 | 最小 44×44px、8px+ 间距、加载反馈 |
| 3 | 性能 | 🟡 高 | WebP/AVIF、懒加载、CLS < 0.1 |
| 4 | 风格选择 | 🟡 高 | 匹配产品类型、SVG 图标、风格一致性 |
| 5 | 布局与响应式 | 🟡 高 | 移动优先断点、无水平滚动 |
| 6 | 字体与颜色 | 🟢 中 | 基础 16px、行高 1.5、语义化颜色 token |
| 7 | 动画 | 🟢 中 | 150-300ms、有意义、空间连续性 |
| 8 | 表单与反馈 | 🟢 中 | 可见标签、就近错误提示、渐进式展示 |
| 9 | 导航模式 | 🟡 高 | 可预测返回、底部导航 ≤5、深度链接 |
| 10 | 图表与数据 | ⚪ 低 | 图例、提示、无障碍配色 |

## 关键设计指南速查

### 可访问性（最关键）
- 最小对比度 4.5:1（大文本 3:1）
- 焦点环 2-4px
- 图标按钮必须有 `aria-label`
- 支持系统字体缩放（Dynamic Type）
- 尊重 `prefers-reduced-motion`

### 触摸交互
- 触摸目标最小 44×44pt（Apple）/ 48×48dp（Material）
- 触摸目标间距 ≥ 8px
- 不要仅依赖 hover
- 异步操作时禁用按钮并显示加载

### 性能
- 图片使用 WebP/AVIF
- 图片懒加载
- 预占位防止布局偏移

### 响应式
- 移动优先断点
- 使用 viewport meta
- 禁止水平滚动
- 禁止固定 px 宽度容器
- 禁止禁用缩放
