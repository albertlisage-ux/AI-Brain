# Codex 对话自动归档到 Obsidian 和 Qdrant

用户希望每次 Codex 对话结束后自动生成结构化摘要，存储到 Obsidian Vault，并增量索引到已有的 Qdrant 向量库。经过讨论，采用方案 C：Obsidian 只保存摘要、决策、行动项等结构化内容，原始对话保留在 ~/.codex/sessions，笔记中记录来源路径。复用现有 ai-brain-rag 项目中的 DeepSeek API 生成摘要、Ollama nomic-embed-text 生成向量、Qdrant 存储向量。实施计划包括：Codex Stop Hook 入队、后台 Worker 防抖处理、SQLite 状态管理、launchd 自动启动、容量监控（不自动删除）。设计规格和实施计划已写入项目文档，用户确认后开始实施。

## Decisions

- 采用方案 C：Obsidian 保存结构化摘要，原始对话保留在 ~/.codex/sessions，笔记记录来源路径
- 复用现有 ai-brain-rag 项目中的 DeepSeek API 生成摘要
- Ollama nomic-embed-text 继续负责向量化
- 复用现有 Qdrant ai-brain collection 和索引器
- 添加 SQLite 状态、失败重试、内容哈希和幂等更新
- 添加 macOS launchd 实现登录后自动运行
- 每月生成 ~/.codex/sessions 容量报告，仅预警，绝不自动压缩、移动或删除
- 原始 transcript 解析单独封装以应对格式变化
- 不读取或写入真实密钥，继续使用已有 .env.local
- 在独立 worktree 和分支 codex/codex-conversation-archive 中实施，保护现有未跟踪笔记
