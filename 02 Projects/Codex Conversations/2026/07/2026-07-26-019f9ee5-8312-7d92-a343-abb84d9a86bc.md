# Codex 全局 Skills 存储与自动路由优化

讨论了如何在本地存储全局 Skills（包括 Superpowers）并实现每次对话根据内容自动调用不同 Skills。最终按推荐方案完成优化：新增 8 个官方 curated Skills，启用 multi_agent，添加全局 Skill 路由规则，保留插件管理的 Superpowers，跳过已有 Skills 和依赖未安装连接器的 Skills。

## Decisions

- 个人全局 Skills 放在 ~/.codex/skills，插件管理的 Skills 保留在插件缓存，不直接修改
- 新增 8 个官方 curated Skills：openai-docs, cli-creator, define-goal, jupyter-notebook, playwright-interactive, gh-address-comments, gh-fix-ci, yeet
- 在 config.toml 中启用 multi_agent = true
- 在 AGENTS.md 中添加全局 Skill 自动路由规则
- 跳过已有 Skills 和依赖未安装连接器的 Skills

## Completed Work

- 盘点现有全局 Skills 和插件提供的 Skills
- 安装 8 个官方 curated Skills
- 启用 Superpowers 的多 Agent 能力
- 写入全局 Skill 路由规则到 AGENTS.md
- 验证配置文件有效，8/8 Skill 入口完整

## Solutions

- 个人 Skills 安装到 ~/.codex/skills/<skill-name>/SKILL.md
- 插件管理的 Skills 通过插件缓存自动加入可用列表
- 自动路由依赖 SKILL.md 中的 description 字段
- 全局路由规则可写入 AGENTS.md 或 config.toml
